Conspodium Installation Guide

1-Click Shared Hosting Deployment for cPanel, LiteSpeed, Apache, and Nginx servers.

1
Upload Web Files
Upload the contents of the public/ folder (or the entire project zip) to your web server root directory (typically public_html or www) via cPanel File Manager or FTP.
2
Set Directory Write Permissions
Ensure that the /data and /uploads folders have writable permissions on your web server: 
chmod 775 data uploads  # or 777 depending on host
3
Run Web Installation Wizard
Open your web browser and navigate to the install.php script: 
http://your-domain.com/install.php
4
Set Admin Credentials & Launch
Enter your custom Admin Full Name, Email, Username, and Password, then click Install Conspodium Now.
🔒 Automated Security Lock: Once installation is complete, the installer automatically generates a data/install.lock file and hides install.php behind an HTTP 404 Not Found guard, securing your live platform against unauthorized resets.
